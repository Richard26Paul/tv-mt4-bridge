🤖 MT4 Expert Advisor (EA) Installation

Download the MT4 Expert Advisor file and install it in MetaTrader 4 to automatically execute trades from webhook signals.

📥 Installation Instructions:

  1. Click the "Download EA File" button below to get TradingViewBridge_EA.mq4
  2. Open MetaTrader 4
  3. Go to File → Open Data Folder
  4. Navigate to MQL4 → Experts
  5. Copy the downloaded .mq4 file into the Experts folder
  6. In MT4, open the MetaEditor (F4) and compile the EA (F7)
  7. Or right-click in Navigator → Refresh to see the EA
  8. Drag the EA onto your chart
  9. Configure input parameters as needed

⚙️ EA Configuration Parameters:

DataFolderFolder name for signal files (default: "Bridge_Data")
CheckIntervalHow often to check for new signals (seconds)
UseFileLoggingEnable detailed logging to files
DefaultLotSizeDefault lot size if not specified in signal
SlippageSlippage allowance in points
AutoCloseAuto-close opposite positions before opening new ones
MagicNumberStrUnique identifier for EA's trades
